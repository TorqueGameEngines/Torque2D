Detailed Description

One entry of the cursor table. Unlike a profile or a border, a cursor is a bitmap, which no recipe can derive from a palette - so the table also carries the stock art a new member starts from and the placement values that art wants. Those three are written once when the member is created and never stamped again; the recipe derives only the tint.

The suffixes deliberately match the canonical cursor names the engine looks up when a control names none ("EditCursor", "LeftRightCursor" and the rest), so installing a theme's cursors under those names is a matter of dropping the theme's own name from the front.
